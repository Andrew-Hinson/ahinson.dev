# HireSite

Glossary for ahinson.dev. Identity and evidence a hiring manager reads, not tools.

## Language

**HireSite**:
The job of this site: convert a hiring manager to an interview. PlatformSignal first.
_Avoid_: project gallery, frontend showcase, blog, Dual site

**SiteIdentity**:
Data Platform Engineer. The site's name for the resume TargetRole.
_Avoid_: Software Engineer, Data Engineer, untitled

**WorkWriteup**:
A short public story of work that cannot be open-sourced. Problem, what was built, outcome.
_Avoid_: project, case study, resume bullet as a heading

**PublicLab**:
A cloneable public repo shown as streaming proof, not the identity. stream-join-lab is the current PublicLab.
_Avoid_: StudySystem, featured project, hero project

**Evidence**:
A WorkWriteup or PublicLab that proves PlatformWork. That is the only reason a project appears.
_Avoid_: Active Projects, Internal Projects, hobby

**CareerTimeline**:
Where and when. Titles and dates. Fetch wins live in WorkWriteups, not as career bullets.
_Avoid_: full resume paste, AME Group
